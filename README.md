# 🎓 CampusExchange - College Marketplace

A full-stack college marketplace platform where students can buy, sell, and exchange items within their campus community.

![CampusExchange Screenshot](https://images.unsplash.com/photo-1523050854058-8df90110c9f1?w=1200&h=600&fit=crop)

## ✨ Features

### 🛒 **Buy & Sell**
- List items for sale with images and descriptions
- Browse items by category (Books, Electronics, Furniture, etc.)
- Advanced search and filtering
- Price negotiation system

### 👤 **User Features**
- College email verification for security
- User profiles with ratings
- Wishlist to save favorite items
- Real-time messaging (Coming Soon)

### 🏫 **Campus-Focused**
- College-specific marketplace
- Campus pickup locations
- Verified student community
- Safe transaction environment

### 📱 **Modern Tech Stack**
- **Frontend**: React.js, Bootstrap, Formik
- **Backend**: Node.js, Express (Ready to implement)
- **Database**: MongoDB (Ready to implement)
- **Authentication**: JWT tokens
